# Piper 机械臂 Xbox 手柄遥操作

本仓库记录使用 Xbox 手柄遥操作松灵 Piper 六轴机械臂的学习过程与实践经验，主要包括安全操作规范、仿真环境练习、真实机械臂操作及官方实现代码参考。

## ⚠️ 1. 重中之重：速度设置与安全规范

**无论在仿真环境还是真实机械臂环境中，速度参数必须保持为以下设定，严禁随意调整。**

- **速度参数：0.25**
- **速度百分比：10%**
- **仿真环境与真实环境的速度设置必须始终保持一致。**

操作前必须检查虚拟环境和真实环境对应的终端，确认两边的速度参数均为 `0.25` 和 `10%`。

操作过程中，时刻注意两个终端的速度设置是否一致。**未经确认，不得擅自更改速度参数。** 如果发现两边参数不一致，应暂停操作，确认并恢复一致后再继续。

> 安全原则：先检查速度，再开始操作；先熟悉仿真，再操作真机。任何时候都不能忽视速度设置与环境之间的一致性。

## 2. 第一阶段：仿真环境练习

正式操作真实机械臂之前，必须先在仿真环境中熟悉 Xbox 手柄的按键布局与控制逻辑。

1. 启动仿真环境及对应的手柄遥操作程序。
2. 检查速度参数是否为 `0.25` 和 `10%`。
3. 熟悉各按键对应的机械臂运动方向与控制功能。
4. 练习单个按键操作，逐步熟悉机械臂的运动响应。
5. 确认理解各按键功能后，再进入真机操作阶段。

## 3. 第二阶段：真实机械臂操作

完成仿真练习后，再进行真实 Piper 机械臂的遥操作。

1. 检查真实机械臂及手柄的连接状态。
2. 确认真实环境的速度参数为 `0.25` 和 `10%`。
3. 再次核对仿真环境与真实环境两个终端的速度设置，确保一致。
4. 在确认周围环境安全、机械臂运动范围内没有人员或障碍物后，开始低风险操作测试。
5. 操作过程中持续关注机械臂运动状态，发现异常立即停止操作并排查原因。

**注意：** 仿真环境中的操作结果不代表真机一定具有相同表现。真机操作前仍需独立进行安全检查，并确保急停方式可用。
